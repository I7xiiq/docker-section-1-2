# Docker Course

A practical, hands-on course that teaches Docker step by step through real examples — no unnecessary theory, just what you actually need to build, run, and deploy containers.

## Section 1 & 2: Introduction & Dockerfile Basics

In this section, you'll learn the fundamentals of Docker and how to write your first Dockerfile.

### Topics covered
- What is Docker and why use it
- Containers vs Virtual Machines
- Installing Docker
- Writing your first Dockerfile
- Building and running image
